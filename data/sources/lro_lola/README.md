# LRO LOLA Source Acquisition Plan

This directory stores reproducible LOLA source evidence for MoonMoon's first
authoritative lunar terrain fixture.

The current repository does not commit the raw LOLA product. It commits tiny
CSVs extracted through HTTP byte ranges. Those CSVs are now the active
first-trusted-square terrain source and the first adjacent route-window sources
for MoonMoon software proof.

## Reproduction

The active source contract is checked data plus MoonBit mirrors. Keep the CSV
artifacts, checksums, extraction windows, and generated MoonBit fixture tables
in sync through MoonBit review and tests. External fetch/extraction tools may
exist outside this repository, but they are not part of the committed source
architecture.

## Trust Gate

Keep the active software-proof fixture accepted only while the following
evidence remains recorded and verified:

- official source family URL and metadata URL
- selected product URL after ODE/PDS discovery
- source metadata SHA-256
- raw image SHA-256 when practical
- reviewed extraction window and projection math
- extracted CSV SHA-256
- ranked corridor scan CSV SHA-256
- widened ranked corridor scan CSV SHA-256
- generated inline grid fingerprint
- checked source paths and checksums in MoonBit tests
- passing `moon test`
