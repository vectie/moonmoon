# Rabbita LOLA Terrain Assets

This directory contains compact derived terrain assets for the Rabbita 3D
viewer. It does not store raw PDS rasters.

## `first_trusted_square_lola_5m_129.json`

- Source product: `LDEM_875S_5M`
- Instrument: LRO LOLA
- Source raster:
  <https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/float_img/ldem_875s_5m_float.img>
- Source label:
  <https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/float_img/ldem_875s_5m_float.lbl>
- Source projection: polar stereographic
- Source resolution: 5 m/pixel
- Tile size: 129 x 129 samples
- Generated by: `npm run prepare:lola-terrain`

The viewer samples this tile for the visible third-person terrain mesh, the
DEM-derived local hillshade, and the Noetix E1 terrain-contact probes. The
scene scales the local elevation delta for robot-scale readability, while
preserving the raw source elevations and metadata in this asset.

Do not apply the global Moon texture to this local walking terrain. A real
image overlay must be imported as a separately aligned LROC/LOLA local tile;
until then, the local surface uses `lola-dem-derived-hillshade` so the visible
texture follows the active heightfield.
