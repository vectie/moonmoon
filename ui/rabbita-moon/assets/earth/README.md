# Earth Backdrop Asset

`earth_atmos_2048.jpg` is used only for the distant Earthrise backdrop in the
Rabbita third-person lunar viewport.

- Source: Three.js example texture `examples/textures/planets/earth_atmos_2048.jpg`
- Source URL:
  <https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/textures/planets/earth_atmos_2048.jpg>
- Runtime marker: `earth-atmos-2048-real-texture`

This asset is visual context only. It is not used for Moon terrain, robot
contact, physics, or mission evidence.
